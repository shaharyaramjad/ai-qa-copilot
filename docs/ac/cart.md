# AC: Cart

Target: https://www.saucedemo.com (log in as `standard_user` / `secret_sauce`)

- AC-CART-1: A logged-in user can add a product to the cart from the product list.
- AC-CART-2: The cart icon shows how many items are in the cart. With no items it shows no count.
- AC-CART-3: A user can remove a product from the product list page, and the count updates.
- AC-CART-4: The cart page lists the added products with their name and price.
- AC-CART-5: A user can remove a product from the cart page.
- AC-CART-6: A user can go back from the cart to the product list with "Continue Shopping".
