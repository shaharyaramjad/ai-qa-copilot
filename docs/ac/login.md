# AC: Login

Target: https://www.saucedemo.com

- AC-LOGIN-1: A user with valid credentials can log in and lands on the product list (inventory page).
- AC-LOGIN-2: A wrong username/password combination shows an error and keeps the user on the login page.
- AC-LOGIN-3: Username is required; submitting without it shows an error.
- AC-LOGIN-4: Password is required; submitting without it shows an error.
- AC-LOGIN-5: A locked-out user cannot log in and sees a clear message.
- AC-LOGIN-6: A logged-in user can log out and return to the login page.

Public demo users: `standard_user`, `locked_out_user` (password for both: `secret_sauce`).
