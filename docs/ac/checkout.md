# AC: Checkout

Target: https://www.saucedemo.com (log in as `standard_user` / `secret_sauce`)

- AC-CHK-1: A user with items in the cart can start checkout from the cart page.
- AC-CHK-2: First name, last name and postal code are required; a missing value shows an error.
- AC-CHK-3: The overview shows item total, tax and total, and total equals item total plus tax.
- AC-CHK-4: Finishing the order shows a confirmation message.
- AC-CHK-5: After an order is completed, the cart is empty.
- AC-CHK-6: A user can cancel on the information page and return to the cart.
