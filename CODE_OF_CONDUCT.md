# Code of Conduct

We want this to be a place where beginners and experienced testers can both learn.

- Be kind and assume good intent. Disagree with ideas, not people.
- Give specific, useful feedback. Explain why, not only what.
- No harassment, discrimination, personal attacks or unwelcome sexual attention, in any form.
- Do not publish other people's private information.
- Credit other people's work.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who repeatedly do. To report a problem, contact the maintainer privately through the GitHub profile of the repository owner.
