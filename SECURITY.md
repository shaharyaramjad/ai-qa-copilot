# Security

This project runs tests against websites and can call an AI model through a key you provide.

- Never commit `.env` or any API key. If you did by mistake, revoke the key first, then remove it from the history.
- Do not run the tools against a site you do not have permission to test.
- To report a security problem in this repository, use GitHub's "Report a vulnerability" (Security tab) instead of a public issue.
